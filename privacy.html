プライバシーポリシー

制定日: 2026年10月24日

hibi-uploader（以下「本ツール」）は、運営者が自分の YouTube チャンネルに動画を投稿するための個人用ツールです。

取得する情報

本ツールは、Google の OAuth 2.0 で YouTube Data API v3 の youtube.upload の権限だけを求めます。取得するのは、動画を投稿するためのアクセストークンとリフレッシュトークンだけで、氏名・メールアドレス・連絡先などの個人情報は取得しません。

使い方

トークンは、運営者が作った動画とそのタイトル・説明文・タグを運営者のチャンネルに投稿するためだけに使います。

保存と共有

トークンは運営者の PC の中だけに保存し、外部のサーバーには送りません（Google の API への送信を除く）。第三者に提供・販売することはありません。

取り消し

許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

本ツールが Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。本ツールは YouTube 利用規約と Google プライバシー ポリシーの下で YouTube API Services を使います。

English summary

hibi-uploader requests only the YouTube Data API v3 youtube.upload scope. It stores the OAuth tokens only on the operator's PC, uses them only to upload the operator's own videos to the operator's own channel, and never shares or sells them. No other personal data is collected. Access can be revoked at any time from your Google Account permissions page. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
