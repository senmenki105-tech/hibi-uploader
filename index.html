hibi-uploader

hibi-uploader は、運営者が自分で作った「今日は何の日」のショート動画を、運営者自身の YouTube チャンネルに投稿するための個人用ツールです。運営者の PC だけで動き、ほかの人に提供するサービスではありません。

使う権限

YouTube Data API v3 の youtube.upload（動画のアップロード）だけを使います。チャンネルの動画の閲覧・削除や、ほかの Google サービスのデータには触れません。

English

hibi-uploader is a personal tool that uploads short videos created by the operator to the operator's own YouTube channel. It runs only on the operator's PC and is not offered to other users. It uses only the YouTube Data API v3 youtube.upload scope.
